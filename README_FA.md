# سیگنال‌یار توبیت — نسخه وب موبایل

این نسخه یک داشبورد فارسی برای تحلیل ساده تکنیکال بازار اسپات و فیوچرز توبیت است. سفارش ثبت نمی‌کند و برای اجرای معامله به کلید API توبیت احتیاج ندارد.

## امکانات
- دریافت کندل‌های عمومی Toobit برای جفت‌ارزهای فهرست‌شده
- محاسبه EMA20، EMA50، RSI14 و نسبت حجم به میانگین
- سیگنال آزمایشی BUY / SELL / WAIT همراه با سطوح تکنیکال
- نمایش قیمت‌های CoinMarketCap (کلید عمومی آزمایشی یا کلید Pro سمت سرور)
- اعلان مرورگر در حالی که صفحه باز است
- نقطه پایانی اختیاری برای دریافت Webhook از TradingView
- رابط موبایل راست‌چین و قابل نصب به صفحه اصلی

## نصب با گوشی اندروید

نیاز است برنامه Node.js اجرا شود. ساده‌ترین راه، اجرای پروژه روی یک سرویس میزبانی Node.js است؛ اجرای سرور به‌صورت محلی روی گوشی نیازمند محیطی مانند Termux است و ممکن است در پس‌زمینه توسط اندروید متوقف شود.

### روش پیشنهادی: میزبانی Node.js
1. فایل ZIP را از حالت فشرده خارج کن.
2. پوشه پروژه را روی یک سرویس میزبانی Node.js بارگذاری کن (سرویس باید Node.js 18 یا جدیدتر و HTTPS پشتیبانی کند).
3. دستور `npm install` را اجرا کن.
4. متغیرهای محیطی را تنظیم کن:
   - `PORT` را در صورت نیاز سرویس میزبانی تعیین می‌کند.
   - `CMC_API_KEY` اختیاری است. کلید را فقط در تنظیمات سرور بگذار، نه در فایل‌های `public`.
   - `TRADINGVIEW_WEBHOOK_SECRET` را با یک رشته تصادفی طولانی عوض کن.
5. دستور `npm start` را اجرا کن.
6. نشانی HTTPS برنامه را در Chrome اندروید باز کن.
7. از منوی سه‌نقطه Chrome گزینه «افزودن به صفحه اصلی» یا «Install app» را انتخاب کن.
8. «فعال‌کردن اعلان» را بزن. اعلان‌های نسخه شروع فقط وقتی صفحه فعال/باز است قابل اتکاست.

### روش محلی در Termux (برای کاربران آشنا به خط فرمان)
1. Termux را از منبع رسمی آن نصب کن.
2. داخل Termux اجرا کن:
   ```sh
   pkg update
   pkg install nodejs-lts unzip
   ```
3. ZIP را در پوشه قابل دسترس Termux قرار بده و استخراج کن.
4. وارد پوشه پروژه شو و اجرا کن:
   ```sh
   npm install
   cp .env.example .env
   nano .env
   npm start
   ```
5. در Chrome گوشی، `http://127.0.0.1:3000` را باز کن.

## CoinMarketCap
- برنامه بدون کلید، endpoint عمومی آزمایشی CMC را امتحان می‌کند؛ محدودیت‌ها و دسترس‌پذیری آن ممکن است تغییر کند.
- برای استفاده پایدارتر، در CoinMarketCap Developer Portal کلید بگیر و آن را در متغیر `CMC_API_KEY` سرور قرار بده.
- کلید را در `app.js` یا هر فایل داخل `public` قرار نده.

## TradingView Webhook
TradingView برای ارسال webhook به نشانی HTTPS عمومی نیاز دارد؛ آدرس localhost گوشی از اینترنت قابل دسترسی نیست. در TradingView یک Alert بساز و URL را روی این بگذار:
`https://YOUR-DOMAIN/api/tradingview`
متن پیام JSON نمونه:
```json
{
  "secret": "همان-مقدار-TRADINGVIEW_WEBHOOK_SECRET",
  "ticker": "{{ticker}}",
  "action": "alert",
  "interval": "{{interval}}",
  "message": "TradingView alert"
}
```
در این نسخه webhook فقط درخواست را اعتبارسنجی و در log سرور ثبت می‌کند؛ هنوز ذخیره‌سازی، ارسال Push و پیوند خودکار آن به صفحه اعلان‌ها پیاده نشده است. هرگز کلید حساب یا رمز عبور را داخل متن webhook قرار نده.

## مسیرهای API
- `GET /api/health`
- `GET /api/market?market=spot&symbol=BTCUSDT&interval=4h`
- `GET /api/market?market=futures&symbol=BTC-SWAP-USDT&interval=4h`
- `GET /api/cmc?symbols=BTC,ETH,SOL`
- `POST /api/tradingview`

## محدودیت‌ها
- قواعد تحلیل نمونه و ساده‌اند؛ قبل از استفاده واقعی باید با داده تاریخی بک‌تست و paper trading شوند.
- سطوح حمایت/مقاومت از بازه اخیر محاسبه می‌شوند، نه از مدل پیش‌بینی.
- داده فیوچرز بر اساس کندل mark price است و ممکن است با قیمت معامله‌شده فرق داشته باشد.
- گزارش روزانه در این نسخه با دکمه ساخته می‌شود؛ زمان‌بندی خودکار روزانه و Push واقعی نیاز به سرویس زمان‌بندی‌شده و ذخیره‌سازی سرور دارد.
- این برنامه مشاوره مالی نیست و سود را تضمین نمی‌کند.
